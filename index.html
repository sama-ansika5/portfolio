About the Project

The Hospital Management System is a web-based application designed to manage hospital operations efficiently. It helps in handling patient records, doctor schedules, appointment booking, and administrative tasks in a digital way.

This system reduces paperwork, improves data accuracy, and makes hospital management faster and more organized.

Key Features

  • Patient Registration
  • Appointment Booking
  • Doctor Management
  • Admin Dashboard
  • Secure Login System
