Project Description

The Hospital Management System is a web-based application developed to simplify hospital operations. It manages patient data, doctor schedules, appointments, and administrative tasks digitally, reducing manual paperwork and improving efficiency.

Modules in the System

1. Admin Module

The admin manages the entire system. Admin can add doctors, view patients, manage appointments, and control system data.

2. Doctor Module

Doctors can view their appointments, check patient details, and update treatment information.

3. Patient Module

Patients can register, book appointments, and view their medical records through the system.

Technologies Used

  • HTML
  • CSS
  • JavaScript

Project Outcome

This system helps hospitals operate more efficiently by digitizing records and improving communication between patients, doctors, and administrators.
